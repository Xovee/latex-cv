# Changelog

## 1.0.2 - 2026-09-03

- Refined the final-page credit to show “LaTeX CV Template by Xovee Xu” with the project URL on a separate line.

## 1.0.1 - 2026-09-03

- Made the template authorship explicit in the default final-page footer.
- Added `\cvhidecredit` and `\cvshowcredit` for submission contexts that require unbranded output.
- Documented attribution and redistribution guidance in the README.

## 1.0.0 - 2026-09-03

- Rebuilt the template around four semantic record families.
- Moved shared typography and layout rules into `xovee-cv.sty`.
- Replaced personal and real-world sample records with fictional placeholders.
- Added pdfLaTeX, XeLaTeX, and LuaLaTeX compatibility checks.
- Rewrote the README with usage, customization, editorial, and release guidance.
- Documented GitHub-to-Overleaf synchronization and MIT license consistency.
